# Foundry Fund Me

A decentralized crowdfunding smart contract built on Ethereum that allows users to contribute funds towards a common goal.

## Built with
Solidity - Smart contract language
Foundry - Development framework

# Getting Started

## Requirements

- [git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)
  - You'll know you did it right if you can run `git --version` and you see a response like `git version x.x.x`
- [foundry](https://getfoundry.sh/)
  - You'll know you did it right if you can run `forge --version` and you see a response like `forge 0.2.0 (816e00b 2023-03-16T00:05:26.396218Z)`


## Prerequsites

- Node.js v16 or higher
- Git
- Foundry


## Quickstart

```
git clone https://github.com/sheriffphx/foundry-fund-me
cd foundry-fund-me
make
```

## Features
Crowdfunding functionality
Minimum funding threshold
Owner withdrawal system
Price feed integrations
Comprehensive test suite
